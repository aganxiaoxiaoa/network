# Windows 便携网络只读诊断工具箱 - 使用说明书

================================================================================
【版本说明】安全只读重构版 (v2.0-ReadOnly)
【适用系统】Windows 10 / Windows 11 (x64)
【运行环境】Windows PowerShell 5.1 原生环境 (无需安装额外依赖)
================================================================================

## 1. 工具定位与设计理念

本工具箱是专为 Windows 宿主机在网络异常、离线或排查故障时设计的**即插即用、纯只读网络诊断与硬件驱动受控备份工具**。

### 核心设计原则
1. **纯只读绝不修改**：严禁调用任何网卡启停、IP 重置、DNS 刷新或代理修改命令，杜绝二次断网。
2. **即插即走零残留**：拔除 U 盘后，宿主机上不残留任何计划任务、服务、注册表自启项或进程。
3. **环境隔离与互斥**：自动探测并避让宿主机本地已运行的网络看门狗，提供单实例互斥锁。
4. **数据安全脱敏**：收集日志时对 Wi-Fi SSID、MAC、公网 IP 等敏感信息进行掩码处理，绝不抓取明文密钥。

## 3. 快速上手

### 方式一：双击启动 (交互式菜单)
1. 插入 U 盘，在资源管理器中打开 `E:\Network-Recovery-USB\`。
2. 双击运行 `START-DIAGNOSIS.cmd`。
3. 弹出控制台窗口，自动加载配置并呈现如下菜单：
   ```text
   ================================================================================
                     Windows 便携网络诊断工具箱 (只读安全版)
   ================================================================================
     [1] 执行完整只读网络健康诊断 (网卡/路由/网关/公网TCP直连/DNS/代理)
     [2] 生成诊断报告与脱敏归档包 (ZIP)
     [3] 导出第三方网络硬件驱动 (PnPUtil 只读备份至 backups 目录)
     [0] 退出工具箱
   ================================================================================
   ```
4. 输入序号并回车即可执行。

### 方式二：命令行非交互模式 (适合脚本或自动化调用)
打开 PowerShell 或 CMD，进入 `E:\Network-Recovery-USB\` 目录：

```powershell
# 1. 打印全量只读健康诊断
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\NetworkDiagnostics.ps1 -Action FullHealth

# 2. 生成脱敏诊断压缩包
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\NetworkDiagnostics.ps1 -Action Bundle

# 3. 导出网络驱动备份 (需管理员权限)
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\NetworkDiagnostics.ps1 -Action BackupDrivers

# 4. 查看帮助
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\app\NetworkDiagnostics.ps1 -Action Help
```

## 4. 核心功能详解

### 4.1 完整只读网络健康诊断 (Action: FullHealth)
分层排查网络故障，不发任何写操作：
- **第一层：硬件与适配器**：物理连接状态、介质状态、链路协商速度（LinkSpeed）、IPv4 地址与掩码。
- **第二层：默认路由与网关**：默认路由是否存在（`0.0.0.0/0`）、下一跳网关地址、跃点数（Metric）、网关 ICMP/ARP 响应性。
- **第三层：公网 TCP 直连握手**：绕过系统代理，直接建立低开销 TCP Socket 握手测试（默认探测阿里 DNS `223.5.5.5:53`、腾讯 DNS `119.29.29.29:53`、百度 `www.baidu.com:443` 等），精确测量毫秒级延迟。
- **第四层：DNS 域名解析**：针对配置的测试域名（如 `www.microsoft.com`）执行 `Resolve-DnsName`，分析解析成功率、解析耗时及 A 记录。
- **第五层：代理环境诊断**：采集当前 WinINET（注册表）及 WinHTTP（系统底层）代理设置，排查是否存在代理残留或异常配置。
- **第六层：核心网络服务状态**：检查 DHCP Client (`Dhcp`)、DNS Client (`Dnscache`)、Network Store Interface (`nsi`)、WLAN AutoConfig (`Wlansvc`) 的运行状态。

### 4.2 诊断报告与脱敏归档包 (Action: Bundle)
在 `output\` 目录下自动生成以时间戳命名的诊断 ZIP 包（例如 `DiagnosticBundle_20260910_014500.zip`），内部包含：
- `Report.json`：全量诊断数据的结构化 JSON，便于机器分析；
- `Report.txt`：格式化的文本版诊断摘要，便于直接查阅；
- `SystemInfo.txt`：系统版本、网络适配器配置、路由表快照；
- `Diagnostics.log`：本次运行的完整日志。
> **脱敏安全特性**：所有导出文件均对 Wi-Fi SSID、BSSID、物理 MAC 地址后段及公网 IPv4 地址自动执行掩码脱敏（例如 `Wi***`、`XX:XX:XX:XX:5E:2B`、`123.***.***.12`）。

### 4.3 导出第三方网络驱动 (Action: BackupDrivers)
在网络彻底瘫痪或怀疑网卡驱动损坏时，可使用本功能将当前系统内已安装的第三方网卡驱动提取备份至 U 盘 `backups\Drivers\`：
- 底层仅调用 Windows 官方命令 `pnputil.exe /export-driver`；
- 执行前严格检测 U 盘剩余空间（必须大于 500MB，不足则拒绝执行）；
- 纯只读导出，绝不执行 `/add-driver`、`/delete-driver` 或 `/restart-device`。

## 5. 常见问题排查 (FAQ)

**Q1: 为什么工具启动时提示“本地网络看门狗正在运行”？**
> 答：这是安全保护特性。工具检测到宿主机 D 盘正在运行 `NetworkRecoveryWatchdog` 监控脚本。为防止两个工具同时运行引发状态冲突，本工具自动锁定为纯只读观察模式，绝不触碰或修改网络。

**Q2: 运行工具需要管理员权限吗？**
> 答：执行只读健康诊断（`FullHealth`）和生成脱敏报告包（`Bundle`）**完全不需要管理员权限**，普通用户权限即可正常运行。仅有“导出驱动（`BackupDrivers`）”功能因调用系统底层的 `pnputil.exe` 导出接口，需要以管理员身份运行控制台。

**Q3: 为什么 `quarantine` 文件夹里的文件无法双击运行？**
> 答：该目录是历史事故版本的物理隔离区。为防止用户或运维误触造成网络再次中断，所有脚本入口均被强制更名为 `.disabled` 后缀，严禁恢复和运行。
